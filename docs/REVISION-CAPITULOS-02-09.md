La comparación por página utilizó hojas de contacto y ampliaciones para caras, ojos, textos y casos dudosos. Cada candidata incorporada se comprobó a página completa y con OCR adicional. El OCR puede omitir filas enteras: la comprobación visual tiene prioridad.

Se comprueban dormitorios, aula, comedor, pasillos y tiendas, además de portadores, cochecitos y escala de los muñecos.
